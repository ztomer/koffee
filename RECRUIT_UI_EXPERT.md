# Koffee App - UI/UX Improvement Plan Request

## About Koffee
A native macOS app for calculating optimal caffeine intake based on weight and sensitivity. Built with SwiftUI, featuring liquid physics simulation as the main visual element.

## Current Issues Identified

### Input Fields
- Weight field allows invalid input (cursor positioning, partial values)
- Time fields have similar UX issues
- Need clearer visual feedback and input handling

### Window
- Currently semi-transparent but could be more polished
- Width recently increased but may need further refinement

### Overall
- App has good bones (liquid simulation, core algorithm) but UI/UX feels unfinished
- Need expert eye to identify friction points and improvements

## What We Need

**A brutal, honest assessment and improvement plan covering:**

1. **Input field UX** - How should weight/time inputs behave? What's the ideal interaction model?
2. **Visual hierarchy** - What's the right balance between the liquid visualization and controls?
3. **Window design** - Transparent vs opaque, sizing, chrome
4. **Micro-interactions** - Focus states, validation feedback, transitions
5. **Information architecture** - What's essential vs noise?

## Deliverable
- A written plan (not code) with specific recommendations
- Could include Figma mocks or just detailed specs
- "Brutal" means we want honest feedback, not polite suggestions
